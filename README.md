# n0xbr3ak3r.github.io

Personal cybersecurity blog and portfolio for Wilson BARIKI.

## Local preview

Requires Ruby/Jekyll.

```bash
bundle install
bundle exec jekyll serve --livereload
```

Open http://localhost:4000

## Deploy

Push to the `main` branch of the `n0xbr3ak3r.github.io` repository and enable GitHub Pages from the repository settings.
